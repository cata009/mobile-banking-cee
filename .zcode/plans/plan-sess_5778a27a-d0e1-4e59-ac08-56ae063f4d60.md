# Plan: Înlocuire sidebar Design System cu tab-uri orizontale elegante

## Context
Sidebar-ul lateral din Design System (`<aside>` cu `InventoryTabs`) trebuie eliminat și înlocuit cu tab-uri orizontale elegante în partea de sus, ca la Flows (`FlowLibraryTabs` — `flex flex-wrap gap-[8px] border-b`, butoane 44px, underline activ teal).

## Decizii confirmate
- **Fără numere** în tab-uri (doar etichete: Components, Templates, Icons, Colors, Typography)
- **Fără link-uri de sub-secțiune** (Headers/Navigation/Buttons etc. eliminate; scroll natural, scroll-spy-ul păstrează hash-ul)

## Modificări (2 fișiere)

### 1. `src/app/screens/design-system/DesignSystemPage.tsx`
- **Elimin `<aside>` sidebar** (liniile 162-170)
- **Adaug tab-uri orizontale** înainte de `<main>`, cu styling-ul de la Flows:
```tsx
<div className="flex flex-wrap gap-[8px] border-b border-[var(--uc-border)]">
  {(["components", "templates", "icons", "colors", "typography"] as const).map((tab) => {
    const isActive = inventoryTab === tab;
    return (
      <button key={tab} type="button" onClick={() => handleInventoryTabChange(tab)}
        className={`relative min-h-[44px] px-[18px] text-[14px] font-bold leading-[18px] transition-colors capitalize ${
          isActive ? "text-[var(--uc-text)]" : "text-[var(--uc-text-muted)] hover:text-[var(--uc-action)]"
        }`}>
        {tab}
        {isActive ? <span className="absolute inset-x-[10px] bottom-0 h-[3px] rounded-t-[3px] bg-[var(--uc-action)]" /> : null}
      </button>
    );
  })}
</div>
```
- **Schimb layout container** din `flex` (row: sidebar + main) în `flex-col` (stack: tab-uri + main), ca la Flows:
  - `mx-auto flex w-full max-w-[1440px] gap-6 px-6 py-8` → `mx-auto flex w-full max-w-[1440px] flex-col gap-[24px] px-6 py-8`
- Păstrez: `inventoryTab` state, `handleInventoryTabChange` (acum schimbă și conținutul `<main>`), `scrollContainerRef`, scroll-spy-ul (liniile 97-157 — actualizează hash/activeSection la scroll), hashchange listener, și tot `<main>` content.

### 2. `src/app/screens/design-system/inventories.tsx` (curățare)
- Elimin logica `isSidebar`/`placement="sidebar"` din `InventoryTabs` deoarece sidebar-ul dispare. Dacă `InventoryTabs` nu mai e folosit nicăieri cu `placement="sidebar"`, elimin ramura sidebar complet. Dacă e folosit și cu `placement="inline"` (verific), păstrez doar ramura inline.
