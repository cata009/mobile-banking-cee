# Evo 2027 Future Preview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a CZ-only `Evo 2027` future release that initially renders the existing App 2027 content while remaining independently addressable.

**Architecture:** Register a new release and Homepage feature, scope both through the existing resolver/selector rules, and route the new feature through the existing App 2027 Home composition. Extend only the release-specific data branches needed to preserve the current CZ App 2027 product/account behavior.

**Tech Stack:** TypeScript, React, Vite, Vitest, React Testing Library.

## Global Constraints

- Evo is available only for `PI`, `CZ`, and `current` design system.
- Evo is a Future preview and must not alter Baseline, CZ Chatbot, CZ Robo, or App 2027.
- The initial Evo visible content matches App 2027.
- The Evo `Accounts` group reuses the CZ Robo evolution account-card model and quick actions, while keeping App 2027's responsive currency badges for each current account.
- No new dependency, migration, destructive operation, or commit is required.
