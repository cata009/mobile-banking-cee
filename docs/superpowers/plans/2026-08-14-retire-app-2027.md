# Retire App 2027 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the retired PI/CZ Future App 2027 release while retaining Evo 2027 unchanged.

**Architecture:** Future choices come from the release registry, feature metadata, project packs, and the demo top-bar ordering. Removing the App 2027 registry entity and feature flag makes old deep links fall back to default; Evo keeps its independent release and feature flag while reusing shared components.

**Tech Stack:** React 18, TypeScript, Vite, Vitest, Testing Library.

## Global Constraints

- Retain exactly `CZ Chatbot`, `CZ Robo`, and `Evo 2027` as PI/CZ Future choices.
- Preserve the UI, flows, fixtures, and behavior of Evo 2027.
- Do not edit unrelated worktree changes.
