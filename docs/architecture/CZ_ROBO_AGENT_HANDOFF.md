# CZ Robo: lucru independent

Poți folosi alt model pentru ajustări în CZ Robo direct în proiectul principal, conform preferinței utilizatorului. Modificările stabilizării sunt deja integrate aici. Atribuie-i exclusiv fișierele CZ Robo pe durata sarcinii; ceilalți agenți lucrează în alte fișiere. Nu este necesar un worktree separat.

Prompt de copiat:

> Lucrează exclusiv pe CZ Robo, direct în checkout-ul principal existent. Citește AGENTS.md și docs/architecture/INDEPENDENT_OWNERSHIP.md. Înregistrează schimbările deja prezente și analizează întâi selecțiile și cerințele pe care ți le dau, apoi implementează ajustările aprobate. Păstrează comportamentul din alte țări, structura comună a portofoliului, navigarea existentă și formatările valutare. Prezentarea Robo este în src/app/screens/investments/robo/, iar politica, reducer-ele și selectorii sunt în src/features/investments/robo/. Entry point-urile vechi rămân compatibile. Nu modifica App.tsx, registrele globale, dependențele, CI sau componentele comune fără alocarea explicită a acelor fișiere. Dacă o ajustare cere un fișier comun, cere schimbarea agentului responsabil de acel fișier. Recitește fișierele înainte de editare și nu suprascrie copii vechi peste munca altor agenți. Nu schimba branch-ul, nu reseta, nu stasha și nu comite modificările altor agenți. Păstrează politica actuală: ziua civilă curentă este capturată la montare, iar override-ul explicit permite teste deterministe; fixture-urile istorice nu se mută odată cu ceasul. Păstrează draftul la întrerupere/revenire și diferența dintre ordinele pending și deținerile executate. Adaugă regresii pentru schimbări de comportament și rulează testele relevante. Predă lista exactă a modificărilor; coordonatorul gestionează commit-urile și verificarea finală npm run verify.

Completează `worktreeRoot` cu calea checkout-ului principal și adaptează lista din `agent-task-cz-robo.example.json` la sarcina concretă. `ownedPaths` acceptă fișiere exacte și directoare terminate în `/**`; nu acceptă glob-uri generale de nume. Include explicit teste, assets, traduceri și documentație noi înainte de lucru. Traducerile generale CZ sunt partajate cu alte funcționalități CZ și au nevoie de coordonare.

În checkout-ul comun, `npm run agent:scope -- --task task.json --base COMMITUL_DE_PORNIRE` vede toate schimbările prezente, inclusiv ale celorlalți agenți. Nu atribui automat acele schimbări agentului CZ Robo. Coordonatorul poate verifica domeniul combinat al sarcinilor, iar fiecare agent predă separat delta sa. Respectarea alocării fișierelor este o regulă de colaborare, nu o blocare fizică; două editări simultane ale aceluiași fișier nu sunt sigure.
