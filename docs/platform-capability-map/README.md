What this platform actually is:

This repository is a `Vite + React` single-page demo shell for showcasing a UniCredit CEE mobile banking experience across product, country, language, scenario, release, design-system, feature-flag, and separated future-flow preview combinations. It behaves like an interactive prototype with stateful screen transitions, localized copy, static mock data, country-gated visual flows, a Romania Mobile PI Kids prototype, a mock-driven Flow Library for future release previews such as RO Round Up and RO Card PIN, CZ/SK/HU/RS/BA/BA_BL/SI Mobile PI Kids homepage concept variants, a Vercel demo access gate, and honest planned-state placeholders, not like a production banking platform with real APIs, persistence, authentication, audit, or automation. Slovakia Kids is currently rebuilt from the supplied Bulbank Teen/Kids document direction, Hungary Kids now uses the supplied CEE Light Restyle homepage direction with a top daily-spend amount separate from the lower all-money total, supplied quick-action glyphs, local themed request-money and send-money flows with draggable pending-action cards, PI-style `****` hidden amount masks, RO Kids-derived HUF Saving goals with list/detail/create/add-money behavior, HU Learn topic/detail/lesson pages with theme-safe image-backed cards, transparent optimized `512x512` topic/lesson artwork, and non-truncated card copy, a single-card `Your cards` panel, a local PI Card Details-inspired card-details page from `Your cards` with Kids-specific Face ID card-data reveal, copyable mock card fields with bottom auto-dismiss toast feedback, freeze/unfreeze card visual state, large gray-section card actions, search above day-divider Kids transactions with daily net totals, shared PI Messages routing from the HU Kids header, local theme personalization including a `Blockcraft` theme with Minecraft-inspired block motion and accessible grass/dirt/torch colors, the shared PI `BottomNavigation` menu with HU-only `Saving` label/piggy icon override and `Learn` label/book icon replacement for Products, HU-label content for the HU Kids `Saving` / `Payments` / `Learn` / `More` tabs, active theme coverage through one HU Kids runtime `HuThemeShell` that treats themes as atmosphere/canvas instead of globally repainting `--uc-*` tokens, exposes neutral native `--pi-*` bridge variables for imported PI cards, and keeps Payments/Learn/More on an accessible themed subpage wash, stabilized Light/Dark/System appearance controls, and theme-aware system chrome blending, and Serbia Kids now uses a HU-inspired safe-spend coach concept with RSD guidance, money moments, goal progress, earn-next tasks, card safety, a money map, and RS-scoped bottom-nav pages.
